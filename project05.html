Project 5: Spirograph Drawing Machine

For this project I used LEGO SPIKE Prime to build a machine that draws spirograph-style geometric patterns. The challenge was to create artistic designs with rotating motors, thinking both like an artist (what designs look best?) and like a mathematician (which variables change the pattern, and can you predict the output from the inputs?).

The machine uses two motors, each turning a gear with a beam attached. The two beams are joined together into a linkage, and a highlighter is fixed to the end of the arm so it draws on a sheet of paper held down on the base with rubber bands. As the motors turn, the pen follows a path set by both rotations at once.

I used coderobots.ai to help write the SPIKE Prime code that runs each motor at a different speed. The difference between the two motor speeds is what shapes the pattern: the project suggested experimenting with both motors at the same speed, with one speed an even multiple of the other, and with speeds that are completely unrelated.
